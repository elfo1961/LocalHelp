# LocalHelp

A multilingual community help & services app built with Ionic + Angular.

## Initial Languages
- Spanish (first release)
- English
- Brazilian Portuguese

## High-level Features (BDD)
- Show a splash page on startup
- Check for internet connectivity
- Allow users to choose a language
- Allow users to switch languages at any time
- Allow login / registration
- Allow users to edit their profile
- Allow users to create and view help requests
- Allow users to create and view service offers
