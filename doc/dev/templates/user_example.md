# Usage Example Template

This template defines the structure for creating user‑facing usage examples in the `doc/user/usage_examples/` folder.  
Each example should describe a real scenario from the user’s perspective and follow the format below.

---

## Title  
A short, descriptive title.  
Example: **Pool Cleaning (Client & Provider POV)**

---

## Scenario  
A brief explanation of the situation the user is in.  
Example:  
“A user needs help cleaning their pool and wants to find someone nearby.”

---

## Goal  
What the user wants to achieve.  
Example:  
“Find a local service provider who can clean their pool.”

---

## Journey  
A step‑by‑step narrative of what the user does and what the app does in response.  
Use numbered steps.  
Example:

1. The user opens LocalHelp.  
2. They navigate to **Help Requests**.  
3. They create a new request or browse existing ones.  
4. They interact with other users (send a request, candidate themselves, etc.).  
5. They complete the action and reach their goal.

---

## Outcome  
A short summary of the result.  
Example:  
“The user quickly receives offers from local pool‑cleaning providers.”

---

## Notes (Optional)  
Use this section for clarifications, variations, or developer‑oriented comments.  
Example:  
“This flow assumes the user is already logged in.”
